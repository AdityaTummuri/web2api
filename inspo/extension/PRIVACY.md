# Privacy Policy for PromptRelay

**Last Updated:** 2026-10-14  
**Applies to:** PromptRelay Browser Extension

PromptRelay was architected from the ground up on a **zero-telemetry, privacy-first, on-device only** foundation.

---

## 1. Zero External Data Transmission
* **No Remote Servers:** PromptRelay has no backend servers, no analytics endpoints, no tracking pixels, and no third-party APIs.
* **No Telemetry:** We do not collect, monitor, log, or sell any telemetry data regarding your browsing habits, prompts, or AI responses.
* **Open Source Verifiability:** The entire source code is available in this repository. Anyone can inspect every network request (which is exactly zero).

## 2. On-Device Local Storage Only
* All data generated by or stored within the extension—including:
  1. Local prompt counters and timestamp markers,
  2. Rate limit threshold preferences,
  3. Handover context capsules and notes,
  is stored strictly in your browser's sandboxed local storage (`chrome.storage.local`).
* Clearing your browser cache or uninstalling the extension permanently purges all stored data immediately.

## 3. Scope of Host Permissions
PromptRelay requests host permissions strictly for the web domains where the user interacts with conversational AI interfaces:
* `https://chatgpt.com/*`
* `https://chat.openai.com/*`
* `https://claude.ai/*`
* `https://gemini.google.com/*`

These permissions are utilized solely to:
1. Render the non-intrusive on-screen helper widget,
2. Track the number of prompts you send during your current active session,
3. Stage the handover prompt into the active chat textarea when you explicitly click the action button.

## 4. No Credential Access
PromptRelay **never** reads, interacts with, or stores:
* Your session tokens,
* Authentication cookies,
* Passwords or credentials,
* Payment or billing details.

## 5. Contact & Audits
Because this is an open-source project without a central server, any security or privacy inquiries can be raised directly via GitHub issues.
