API Integration Guide

Integrate the automated Gemini service into your standard Python or web applications by calling the local POST API endpoint. It handles queued sequential execution.

1. Curl CLI request

curl -X POST http://localhost:8000/api/chat \ -H "Content-Type: application/json" \ -d '{"prompt": "Explain Quantum Computing in one simple sentence."}'

2. Python requests Integration

import requests

url = "http://localhost:8000/api/chat"
payload = {
    "prompt": "Write a 3-word slogan for a coffee shop.",
    "timeout_sec": 90
}

response = requests.post(url, json=payload)
data = response.json()
print("Response:", data["response"])
print("Latency:", data["latency_ms"], "ms")
